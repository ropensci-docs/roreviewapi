# Summarise counts of 'srr' standards from full 'srr' report

Summarise counts of 'srr' standards from full 'srr' report

## Usage

``` r
srr_counts_summary(srr_rep, has_errors = FALSE)
```

## Arguments

- srr_rep:

  An 'srr' report generated by the
  [`srr::srr_report()`](https://docs.ropensci.org/srr/reference/srr_report.html)
  function.

- has_errors:

  This is `TRUE` when the 'srr' report has errors, in which case the
  final message issued here excludes statements about package being able
  to be submitted.

## Value

Character vector with markdown-formatted summary summary of numbers of
standards complied with.
