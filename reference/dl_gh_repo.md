# Download a GitHub repo to local cache

Download a GitHub repo to local cache

## Usage

``` r
dl_gh_repo(u, branch = NULL)
```

## Arguments

- u:

  URL of GitHub repository

- branch:

  Checkout specified (non-default) branch of repo.

## Value

Path to locally cached '.zip' version of repository
