# Collate list of checks to single concatenated character string

Collate list of checks to single concatenated character string

## Usage

``` r
collate_editor_check(checks)
```

## Arguments

- checks:

  Result of `pkgcheck::pgkcheck` function

## Value

Single character

## Note

Exported only for access by plumber; not intended for general external
usage.
